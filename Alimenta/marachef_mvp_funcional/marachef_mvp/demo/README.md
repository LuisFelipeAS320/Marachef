# Material da demonstração

- `receitas-para-iniciantes.pdf` contém as três receitas de teste fornecidas para a MaraChef. A ficha de cada prato usa os trechos e as páginas do documento original.
- `ovos-mexidos-com-cogumelos.webm` é **Scrambled eggs with mushrooms and cheese**, de **Laila Alsabah**, publicado no Wikimedia Commons sob **CC BY-SA 4.0**. O arquivo mantém a imagem e o áudio originais. O nome local foi encurtado. [Arquivo e autoria](https://commons.wikimedia.org/wiki/File:Scrambled_eggs_with_mushrooms_and_cheese.webm) · [Licença CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
- `catalogo.json` contém a análise revisada do vídeo e os embeddings dos trechos de demonstração. A instalação reconstitui o catálogo a partir desses arquivos.

O instalador publica os quatro pratos na coleção **Demonstração**. O estudo de caso institucional pode ser importado separadamente em uma máquina que tenha uma cópia autorizada.
